First tagged release of `meme-cli`: a [memegen.link](https://memegen.link)-style
meme generator in Go. Point it at a directory of template configs — or use the
~220 templates bundled into the binary — and it composites captions onto
backgrounds, auto-sizing bold-caps text to fit each text box.

```
meme-cli render the-scream "WHEN THE DEPLOY FAILS" "ON A FRIDAY"
```

## Highlights

- **~220 bundled templates, zero setup.** No network calls, no service to
  run. Point `--meme-dir`/`$MEME_DIR` at your own directory (e.g. a
  container volume mount) to use a different library instead.
- **Built for agents, not just humans.** `meme-cli llms` prints a compact
  command/data reference sized for an AI agent to read once and act on;
  `list`/`show` both support `--json` for structured output; distinct exit
  codes (`2` = template or meme-dir not found, `1` = everything else) let a
  caller tell "doesn't exist" apart from "exists but is broken" without
  parsing stderr.
- **Pure Go, no cgo.** Image compositing runs on `golang.org/x/image` and
  `github.com/golang/freetype` — a single static binary, no system image
  libraries required.
- **More than axis-aligned boxes.** Templates can define a rotated or
  perspective `quad` write face (slanted signs, angled surfaces), not just
  rectangular text boxes.

## Install

```
curl -fsSL https://raw.githubusercontent.com/ofthemachine/meme-cli/main/install.sh | sh
```

Downloads a checksummed static binary for your OS/arch into `~/.local/bin`
(override with `MEME_CLI_INSTALL_DIR`) — no Go toolchain required. Or build
from source; see the [README](https://github.com/ofthemachine/meme-cli#building-from-source).

## Commands

```
meme-cli list [--json]              # every template's id + name
meme-cli search <query>             # find templates by id/name/keyword
meme-cli show <template-id> [--json]  # inspect a template's layout
meme-cli render <template-id> [text...] [-o out.png]
meme-cli llms                       # reference for AI agents
```
